# Generátor štruktúry bakalárskej práce

Jednoduchý nástroj, ktorý ti pomôže pripraviť štruktúru bakalárskej práce a pripravené prompty na generovanie jednotlivých kapitol pomocou AI.

## Ako používať

1. Otvor stránku: **https://pumba145.github.io/bakalarska-praca-generator/**
2. Zadaj tému práce
3. (Voliteľne) doplň odbor a jazyk
4. Klikni na **Vygenerovať štruktúru a prompty**
5. Skopíruj pripravené prompty a použi ich v Grok, ChatGPT alebo inom AI nástroji

## Dôležité upozornenie

Tento nástroj slúži len ako **pomocník**. 
Finálnu prácu musíš prepracovať, doplniť vlastné zdroje, myšlienky a praktickú časť. 
Odovzdanie čisto AI generovaného textu môže byť na škole považované za porušenie akademickej integrity.

## Technológie

- Čistý HTML + Tailwind CSS + vanilla JavaScript
- Beží na GitHub Pages (bez backendu)
